## Portfolio Milestones

### Phase 1: Quick Wins (Week 1-2)
- [ ] Choose primary skill area
- [ ] Set up tools
- [ ] Complete 1 beginner web OR video OR design project
- **Target:** 1 completed project

### Phase 2: Building Confidence (Week 3-4)
- [ ] Complete 2-3 projects in primary skill
- [ ] Start learning second skill area
- [ ] Begin documenting process
- **Target:** 3-4 completed projects total

### Phase 3: Diversification (Week 5-8)
- [ ] Complete projects in 2 different skill areas
- [ ] Create case studies
- [ ] Gather feedback from communities
- **Target:** 7-10 completed projects

### Phase 4: Depth & Polish (Week 9-12)
- [ ] Polish best 5-7 projects
- [ ] Add process documentation
- [ ] Create website to showcase work
- **Target:** 10-12 quality portfolio pieces

## Feedback & Community

### Share Work For Feedback
- **Reddit:** r/webdesign, r/videography, r/design
- **Discord:** Tool-specific communities
- **Communities:** Designer Hangout, ADPList (free mentorship)
- **Friends/Family:** Honest feedback from non-designers

### Feedback to Request
1. What stands out first?
2. Does it clearly communicate the message?
3. What could be improved?
4. Would you use/hire for this?
5. How does it compare to [competitor]?
