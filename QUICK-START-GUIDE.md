### DAY 4: Create Your Profiles

#### Upwork Profile
1. Go to upwork.com
2. Sign up
3. Fill out: Profile photo, headline, description
4. **Headline Example:** "Web Designer | Landing Pages & Portfolio Sites"
5. **Description:** Write 3-4 sentences about VividFlow Studio
6. Upload profile photo (professional looking)
7. Set hourly rate: $20-30/hour initially (raise later)
8. Skills: Select your primary skill area

**⏱️ Time:** 45 minutes

#### Fiverr Profile  
1. Go to fiverr.com
2. Sign up
3. Set profile picture (same as Upwork)
4. Create first "Gig" (service offering)
5. **Gig Example:** "I'll create a professional landing page in Webflow"
6. Set price: $100-300 for first gig
7. Add clear description & deliverables
8. Wait for profile review (24-48 hours)

**⏱️ Time:** 1 hour

1. Create workspace for "VividFlow Studio"
2. Create databases for:
   - [ ] Portfolio projects (tracker)
   - [ ] Clients (future)
   - [ ] Time tracking

## Common Obstacles & Solutions

### "I'm not good enough yet"
- **Solution:** Your portfolio doesn't need to be perfect, it needs to show GROWTH. Include 3-4 good projects + process documentation.

### "This is taking longer than expected"
- **Solution:** All skills take time. Compare your Week 1 project to Week 8 project. The progress is real.

### "I don't know what to build for my portfolio"
- **Solution:** See Portfolio Project Ideas document. Pick projects from there. Don't overthink it.

### "Nobody's hiring me"
- **Solution:** You need 5-7 quality portfolio pieces minimum. After that, reach out directly to potential clients. Don't just wait for inquiries.

### "I'm spending too much time on one project"
- **Solution:** Set time limits. 3-4 hours max for early projects. Ship it and move to the next one.
