# VividFlow Studio

Public-facing website and portfolio for VividFlow Studio.

Live: https://bibhu342.github.io/vividflow-studio/

## Stack

Hand-written HTML, CSS and vanilla JavaScript. No build step or framework.

```text
index.html
assets/
  css/style.css
  js/main.js
  img/
```

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

GitHub Pages deploys the repository root from `main`.

## Repository scope

This repository contains only public website/portfolio files. Internal agency operations, client workspaces, production prompts, private planning, and AI operating instructions belong in the private VividFlow workspace and are not stored here.
