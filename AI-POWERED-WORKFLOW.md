## Claude Prompt Templates

### TEMPLATE 1: Web Landing Page

```
Create a professional landing page for [project name].

Client background: [Who is this for?]
Goal: [What should visitor do?]
Target audience: [Who visits?]

Sections needed:
1. Hero - headline, subheadline, CTA button
2. [Section type] - [description]
3. [Section type] - [description]
4. [Section type] - [description]
5. Footer - contact, social links

Design requirements:
- Colors: [color palette]
- Tone: [professional/playful/corporate]
- Must be mobile responsive
- Modern, clean aesthetic
- [Any other requirements]

Return: Complete HTML + CSS + JavaScript file
Should work standalone (no external dependencies)
```

### TEMPLATE 2: Social Media Graphics

```
Design a social media graphics package for [brand].

Brand info:
- Business: [What do they do?]
- Target audience: [Who follows them?]
- Voice: [How do they communicate?]

Package: [Number] unique designs

For each design, provide:
- Title/purpose (e.g., "Motivational Monday")
- Layout description (what goes where)
- Color breakdown
- Typography (fonts, sizes)
- Image/visual elements needed
- Key copywriting/headline
- Design principles applied

Make designs cohesive but visually interesting.
```

### TEMPLATE 3: Video Script

```
Write a [length] second video script for [purpose].

Video details:
- Format: [screen recording/voiceover/etc]
- Platform: [YouTube/TikTok/LinkedIn/Instagram]
- Target audience: [Who watches?]
- Key message: [Main point to convey]
- Call to action: [What should they do?]

Scene breakdown:
[Provide timing and what happens in each scene]

Requirements:
- Professional but [tone] tone
- Hook in first [X] seconds
- Include natural pauses for visuals
- Time each section precisely
- Conversational language

Format response as:
[TIME] [SCENE] | [VOICEOVER TEXT]
```

### TEMPLATE 4: Brand Logo Concept

```
Create logo concepts for [brand].

Brand information:
- What they do: [Description]
- Target market: [Who do they serve?]
- Personality: [Words describing brand]
- Industry: [Category]

Visual direction:
- Style: [Modern/playful/minimal/bold]
- Colors: [Preferred palette]
- Should evoke: [Feelings/associations]
- Must work at: [Small (favicon) to large (billboard)]

Provide:
- 3 different logo concept descriptions
- Explain symbolism of each
- Color variations for each
- Typography pairing recommendations
- How it works at different sizes
- Usage guidelines

Be creative but professional.
```

### TEMPLATE 5: Design System/Brand Guide

```
Create a brand identity system for [company].

Overview:
- Business: [What do they do?]
- Target: [Who do they serve?]
- Positioning: [How are they different?]
- Brand words: [3-5 adjectives]

Provide:
1. Color palette
   - Primary color (with reasoning)
   - Secondary colors
   - Accent colors
   - Neutrals (text, backgrounds)

2. Typography
   - Heading font recommendation
   - Body font recommendation
   - Sizing scale
   - Line height guidelines

3. Visual style
   - Photography style
   - Illustration approach
   - Icon style
   - Pattern/texture usage

4. Voice & tone
   - Key communication principles
   - Sample copywriting
   - Phrases to use/avoid

5. Design elements
   - Logo variations
   - Badge/icon suggestions
   - Button styles
   - Spacing guidelines
```

## FAQ: Using Claude for Design

**Q: Isn't this cheating?**  
A: No. Architects use CAD software, designers use Figma, developers use GitHub Copilot. Claude is your tool. You provide strategy, feedback, direction. Claude executes.

**Q: Will clients accept AI-made designs?**  
A: Yes, if they're high quality and customized. You're the strategist who gathered requirements, gave direction, and refined the output.

**Q: How do I improve if AI does the work?**  
A: You learn by directing, iterating, and refining. After 10 projects, you'll understand design deeply.

**Q: What if Claude can't do something?**  
A: You learn the tool (Canva, CapCut, etc.) and do it manually. But 80% of projects will work with Claude.

**Q: Should I tell clients I use Claude?**  
A: It's your choice. Most care about results, not the process. Some might ask—be honest. The design quality is what matters.
