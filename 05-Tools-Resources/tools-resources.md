## Design & Web Tools

### WEB DESIGN TOOLS

#### Primary Option: Figma + Webflow
| Tool | Purpose | Cost | Learning | Status |
|---|---|---|---|---|
| **Figma** | UI/UX design, prototyping | Free/Pro ($12/mo) | 10-20 hours | ⬜ To Setup |
| **Webflow** | Website builder & CMS | Free/paid ($12-99+/mo) | 20-30 hours | ⬜ To Setup |

**Why this stack?**
- Figma is industry-standard for design
- Webflow is designer-friendly, no coding required
- Both offer free tiers for learning
- Large learning communities

**Alternative Stack: WordPress + Elementor**
| Tool | Purpose | Cost | Learning | Status |
|---|---|---|---|---|
| **WordPress** | Website platform | Free (hosting $5-20/mo) | 10-15 hours | ⬜ To Setup |
| **Elementor** | Page builder | Free/Pro ($99+/year) | 8-12 hours | ⬜ To Setup |

**Why alternative?**
- Lower overall cost
- More hosting options
- WordPress skills valuable for clients
- Less visual than Webflow

### VIDEO EDITING TOOLS

#### Primary Option: DaVinci Resolve
- **Cost:** Free (Studio version $295 one-time)
- **Learning Curve:** Medium (20-40 hours)
- **Features:** Professional editing, color grading, fusion (effects)
- **Hardware:** Requires decent computer (8GB+ RAM)
- **Status:** ⬜ To Setup

#### Secondary Option: CapCut (Quick & Easy)
- **Cost:** Free
- **Learning Curve:** Easy (5-10 hours)
- **Features:** Fast editing, trending effects, mobile-friendly
- **Perfect For:** Social media, quick turnarounds
- **Status:** ⬜ To Setup

#### Premium Alternative: Adobe Premiere Pro
- **Cost:** $22.49/month (Creative Cloud)
- **Learning Curve:** Hard (30-50 hours)
- **Features:** Industry standard, integration with After Effects
- **Best For:** Full-time professional video work
- **Status:** ⬜ If Budget Allows

#### Primary Option: Figma
- **Cost:** Free/Pro ($12/month)

## Hardware & Software Requirements

### Minimum Computer Specs
- **OS:** Windows 10+ or macOS 10.13+
- **RAM:** 8GB (16GB recommended for video editing)
- **Storage:** 256GB SSD (fast project loading)
- **Processor:** Intel i5/AMD Ryzen 5 or better
- **Display:** 1080p minimum (1440p or 4K preferred for design)

### Recommended Gear (Not Essential)
- **Monitor:** External display (24"+ helps with design)
- **Keyboard:** Mechanical keyboard (productivity, comfort)
- **Mouse:** Ergonomic mouse (long hours of work)
- **Headphones:** Good audio for video work (checking sound)

### Internet
- **Speed:** 25 Mbps+ (for file uploads, cloud tools)
- **Backup:** 2 internet sources if possible (client calls important)
- **Tools:** Backup internet hotspot for outages
